# Grate+

A simple mod that adds some new variants of grate based on vanilla blocks.

## Screenshots

![Blocks](screenshots/grates_and_original_blocks.png)
![Items](screenshots/grate_items.png)

## Added Variants of Grates

- Amethyst
- Diamond
- Emerald
- Gold
- Iron
- Lapis
- Netherite
- Redstone
